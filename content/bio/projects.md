# Projects

Here are some of the notable projects I have worked on, demonstrating my ability to build complete applications from concept to deployment.

## E-Commerce Platform
A fully-featured e-commerce platform built with Next.js, Node.js, and MongoDB.
- **Features:** User authentication, product search and filtering, shopping cart, secure checkout with Stripe integration, and an admin dashboard.
- **Impact:** Handled over 10,000 monthly active users with 99.9% uptime.
- **Technologies:** TypeScript, Next.js, Express, MongoDB, Stripe API.

## Task Management App
A productivity application designed to help teams organize tasks and collaborate effectively.
- **Features:** Real-time updates using WebSockets, drag-and-drop Kanban boards, role-based access control.
- **Impact:** Increased team productivity by 20% during internal trials.
- **Technologies:** React, Redux, Firebase, Tailwind CSS.

## Weather Data Aggregator
A data pipeline and visualization tool that aggregates weather data from multiple APIs.
- **Features:** Scheduled data fetching, historical data analysis, interactive charts.
- **Impact:** Provided researchers with easy access to comprehensive weather trends.
- **Technologies:** Python, Pandas, Django, Chart.js.

- **Technologies:** Next.js, MDX, Vercel.
